Network Doctor

宽带故障检测助手

家庭网络偶发卡顿的定位工具。同时测路由器和外网，自动判断问题出在家里 WiFi、外部线路，还是某个设备的后台任务——零依赖，完全在你自己电脑上跑，数据不上传。

特点

零依赖

只用 Python 标准库，不用装任何第三方包。

交叉验证

默认测两个独立公共 DNS，避免单个目标自己抽风被误判成你家网络的问题。

自动识别规律

区分"固定周期跳高"（多是设备后台任务）和"连续整段掉线"（多是线路掉线重拨）。

本地网页界面

开始/停止按钮 + 实时曲线，不用碰命令行。

断线不丢进度

网页刷新或关掉标签页，后台继续记录，重新打开自动接上。

数据不上传

完全在本机运行，所有记录只保存在你自己电脑上。

怎么用

  1. 下载代码 — clone 这个仓库到你的电脑（macOS / Linux，需要 Python 3.7+，系统自带即可）
  2. 启动 — macOS 双击 启动网络监测.command，或在终端运行 python3 server.py，会自动打开浏览器
  3. 开始监测 — 网页里点"开始监测"，建议至少跑 10 分钟，偶发卡顿建议更久
  4. 看结果 — 停止后自动生成结论和曲线图，卡顿在哪一段一目了然，也能直接拿这份报告去找运营商报修
